## Overview
A modern, responsive Todo List application built with React. This web application allows users to organize their tasks efficiently with a clean, intuitive interface.
## Live Demo
This project is deployed on Vercel and can be accessed at [https://react-todo-app-phi-two.vercel.app/](https://react-todo-app-phi-two.vercel.app/)
## Features
- Create, update, and delete tasks
- Mark tasks as completed
- Mobile-responsive design
- Progressive Web App (PWA) capabilities with service worker support
- Clean and intuitive user interface

## Technology Stack
- React.js
- CSS for styling
- Service worker for offline functionality

## Getting Started
1. Clone this repository
2. Install dependencies using npm: `npm install`
3. Run the development server: `npm start`
4. Build for production: `npm run build`
